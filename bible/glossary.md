# Glossary — Think Python key terms

Look up names, frameworks, terms and versions here instead of re-reading chapters.

## Book identity
- **Title:** Think Python: How to Think Like a Computer Scientist
- **Author:** Allen Downey (Green Tea Press, Needham, Massachusetts)
- **Edition indexed:** 2nd Edition, Version 2.4.1 (Python 3 throughout)
- **Licence:** Creative Commons Attribution-NonCommercial 3.0 Unported (CC BY-NC 3.0)
- **Origin:** Adapted from Downey's Java textbook; Jeff Elkner translated it to Python; first Python version 2001.

## Core vocabulary (defined at first use in the book)
- **Program, algorithm, bug, debugging:** Ch 1. Debugging split into syntax, runtime, and semantic errors (expanded in Appendix A).
- **Expression, statement, assignment, operator precedence:** Ch 2.
- **Function, argument, parameter, return value, fruitful vs void function, stack diagram:** Ch 3, 6.
- **Encapsulation, generalization, refactoring, interface design, docstring:** Ch 4.
- **Recursion, base case, infinite recursion:** Ch 5.
- **Iteration, while loop, algorithm (Newton's method):** Ch 7.
- **Sequence, slice, immutable, aliasing:** Ch 8, 10.
- **Dictionary, hashtable, memo, key-value pair:** Ch 11 (hashtable analysis in Appendix B).
- **Tuple, tuple assignment, DSU pattern (decorate-sort-undecorate):** Ch 12.
- **Persistence, exception handling, pickle/shelve, pipe:** Ch 14.
- **Class, object, instance, attribute, method, inheritance, polymorphism, operator overloading:** Ch 15–18.
- **List comprehension, generator expression, set, Counter, defaultdict, named tuple, kwargs:** Ch 19.

## Method (how the book teaches)
- Short chapters, minimal jargon, terms defined at first use.
- Gradual build-up; hard topics split into small steps to avoid trap doors.
- Debugging section and Glossary at the end of every chapter; exercises with linked solutions.
- Case studies: interface design (Ch 4), word play (Ch 9), data structure selection (Ch 13), poker hands (Ch 18).
