# Timeline

- **1999 (Jan):** Downey writes the first version (in Java) in two weeks before teaching an intro class; titled How to Think Like a Computer Scientist.
- **2001:** Jeff Elkner's Python translation published by Green Tea Press.
- **2003:** Downey starts teaching Python at Olin College.
- **2015:** 2nd Edition — all code updated to Python 3; debugging sections, case studies, and appendices added.
- **Version 2.4.1:** The exact version indexed in this repo (from thinkpython2.pdf).
- **Later:** 3rd edition published at thinkpython.com (not indexed here).
