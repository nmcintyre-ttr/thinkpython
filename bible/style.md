# Style: Downey's voice, written as rules

- **First person, teacher to student.** Downey addresses "you", the beginning programmer, with classroom anecdotes ("When I teach this class...").
- **Short and careful.** Stated goals: keep it short (better to read 10 pages than not read 50), minimize jargon, define each term at first use, build gradually.
- **Structure per chapter:** concept sections in numbered order, a Debugging section, a Glossary, then Exercises.
- **Code first, theory second.** Small runnable examples precede formal definitions; stack diagrams visualize execution.
- **US spelling** in the source text (e.g. "organize" appears in exercises); glossary terms are bolded at first use in the original.
- **Era markers:** Python 3 transition era (2015, 2nd ed.); browser-based Python environments recommended for beginners.
