**Covers:** Assignment statements, variable naming rules, expressions vs statements, script mode, order of operations, string operations, and comments. Establishes the vocabulary for reading and writing simple Python programs.

- Core topic: variables, expressions and statements in Python 3, taught incrementally with small examples.
- Every chapter ends with a Debugging section (general techniques and Python pitfalls) and a Glossary of terms defined at first use.
- Exercises range from short checks of understanding to substantial projects, most with linked solutions.

## What the reader takes away
- Assignment statements, variable naming rules, expressions vs statements, script mode, order of operations, string operations, and comments.
