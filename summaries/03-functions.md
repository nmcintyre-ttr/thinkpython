# Chapter 3: Functions — summary

**Covers:** Function calls, math functions, composition, defining new functions, flow of execution, parameters and arguments, local scope, stack diagrams, and fruitful vs void functions. Explains why functions exist: abstraction, reuse, and decomposition.

## Key points
- Core topic: functions in Python 3, taught incrementally with small examples.
- Every chapter ends with a Debugging section (general techniques and Python pitfalls) and a Glossary of terms defined at first use.
- Exercises range from short checks of understanding to substantial projects, most with linked solutions.

## What the reader takes away
- Function calls, math functions, composition, defining new functions, flow of execution, parameters and arguments, local scope, stack diagrams, and fruitful vs void functions.
- Practical, runnable patterns rather than language trivia: Downey's stated method is short chapters, minimal jargon, and gradual build-up to avoid trap doors.
