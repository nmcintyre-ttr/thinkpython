# Chapter 18: Inheritance — summary

**Covers:** Card objects, class attributes, comparing cards, decks, inheritance, class diagrams, data encapsulation, and a poker hand case study. Subclasses that inherit and override behaviour.

## Key points
- Core topic: inheritance in Python 3, taught incrementally with small examples.
- Every chapter ends with a Debugging section (general techniques and Python pitfalls) and a Glossary of terms defined at first use.
- Exercises range from short checks of understanding to substantial projects, most with linked solutions.

## What the reader takes away
- Card objects, class attributes, comparing cards, decks, inheritance, class diagrams, data encapsulation, and a poker hand case study.
- Practical, runnable patterns rather than language trivia: Downey's stated method is short chapters, minimal jargon, and gradual build-up to avoid trap doors.
