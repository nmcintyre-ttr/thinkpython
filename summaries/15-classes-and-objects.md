# Chapter 15: Classes and objects — summary

**Covers:** User-defined types, attributes, instances as return values, objects are mutable, copying, and pure functions vs modifiers. Introduces object-oriented programming with points and rectangles.

## Key points
- Core topic: classes and objects in Python 3, taught incrementally with small examples.
- Every chapter ends with a Debugging section (general techniques and Python pitfalls) and a Glossary of terms defined at first use.
- Exercises range from short checks of understanding to substantial projects, most with linked solutions.

## What the reader takes away
- User-defined types, attributes, instances as return values, objects are mutable, copying, and pure functions vs modifiers.
- Practical, runnable patterns rather than language trivia: Downey's stated method is short chapters, minimal jargon, and gradual build-up to avoid trap doors.
